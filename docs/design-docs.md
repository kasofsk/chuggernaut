# Design documents: the header contract

**This page has moved into the doc policy.** The design-doc header contract —
the `# ` title line, the `Status:` line and its length bound, the vocabulary in
use, and how a document reaches the operator UI's Designs view — is stated in
[`docs/reference/docs.md`](reference/docs.md#the-header-contract), alongside the
rest of the rules for writing docs here.

It is one page rather than two because the header contract is part of the same
policy as the mutable-head/append-only-body discipline it serves, and a rule
stated in two places drifts in one of them (design
[#415](design/415-knowledge-architecture.md) D4/D14).

This file stays put so the links that already name it still resolve — several of
them sit in append-only design bodies, where a citation is a record of what was
read at the time and is not rewritten.
